时间复杂度分析，1s限制，n<=100 O($$n^3$) $10^6$次循环量级即可

为什么要用二维？

答：因为一维数组记录的信息过少，无法进行状态转移

例如 记录下采到第 i 个药的最大值，无法同时引入状态转移所需的时间和价值

         记录下还剩下 i 的时间，无法同时转移采药状态和价值

定义 dp[i][j] 为决定完前 i 个药采不采后，时间还剩 j 时的最大价值

t[i] 表示时间，v[i] 表示价值

dp [0][j] = 0

dp [1][j >= t[1]] = v[1]

这样有如下状态转移方程 dp[i][j] = max(dp[n-1][j + t[n] + v[n], dp[n-1][j]) 

状态为 i 药 j 时间的最大价值 为下面之一

1. 采的话，就是 前 n-1 药，时间剩下 j + t[n] 的最大价值，来获取第 n 个药的价值，就是 dp[n-1][j + t[n]]

2. 不采的话，就是 前 n-1 药，时间都给前面的药，获取的最大价值，就是dp[n-1][j]

如此 对于最终结果dp [n][0] （用所有的时间来采前 n 个药）来说，可以被 max(dp[n-1][ t[n] ] + v[n], dp[n-1][0]) 转移得来

最后统计下时空复杂度是否有问题

时间为 O($$n*m$) $10^5$ 循环量级符合要求

空间为 int 数组 100x1000 大约 0.4 MB (10^6 的 int 大约为 4MB)
